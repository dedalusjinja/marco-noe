VERSIONE PREMIUM - GITHUB PAGES

Contenuti:

- invito.png

Installazione:
1. Crea una sottocartella del tuo sito, ad esempio /anniversario/
2. Carica index.html e invito.png nella stessa cartella.
3. Apri l'URL della cartella da smartphone.

Effetti:
- busta avorio
- sigillo in ceralacca
- apertura lenta della patta
- estrazione del biglietto
- bagliore finale
- biglietto a pieno schermo

Non usa librerie esterne.
